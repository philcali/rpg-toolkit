# RPG Toolkit

This is a Rust / Bevy implementation of a generic, hand-rolled RPG editor for retro style
RPG games. The purpose of this project is to perform the heavy lifting for creating a visual
narrative for story based adventure games. The project is also loosely opinated (minus the use of Bevy),
in that users can breakout and augment their games with their own plugin set.


## Phased Delivery

The project is ambitious, so we are targetting "useful" phased delivery:

- Phase 1: A working editor for projects, maps, and tileset painting
- Phase 2: Running a live demo with a character
- Phase 3: Applying properties to the map within the editor
